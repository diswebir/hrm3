# هم‌آوا HRM — سامانه ماژولار مدیریت منابع انسانی

نسخه ۱٫۰ · PHP 8.1+ · SQLite · رابط فارسی و راست‌چین

هم‌آوا یک برنامه وب PHP بدون وابستگی build یا سرویس بیرونی است که برای نصب روی هاست اشتراکی cPanel آماده شده است. داده‌ها در SQLite ذخیره می‌شوند و نصب اولیه از طریق مرورگر انجام می‌شود.

## نصب سریع روی cPanel

1. نسخه PHP را روی **۸٫۱ یا بالاتر** قرار دهید و افزونه‌های `PDO` و `PDO_SQLite` را فعال کنید.
2. محتوای پروژه را در پوشه‌ای که دامنه به آن اشاره می‌کند بارگذاری و Extract کنید.
3. پوشه `storage` باید برای PHP قابل نوشتن باشد (معمولاً `0750` یا `0770`؛ از `0777` استفاده نکنید مگر پشتیبانی هاست صراحتاً راهنمایی کند).
4. با مرورگر به `https://your-domain.example/install.php` بروید، پیش‌نیازها را بررسی و مدیر سامانه را بسازید.
5. پس از نصب، با حساب مدیر وارد شوید؛ از بخش **کاربران و دسترسی‌ها** همکاران و نقش‌ها را اضافه کنید.

راهنمای کامل: [`docs/CPANEL_FA.md`](docs/CPANEL_FA.md)

## پیش‌نیازها

- PHP 8.1 یا جدیدتر
- PDO و `pdo_sqlite` فعال
- Apache با پشتیبانی `.htaccess` (برای محدودسازی فایل‌های خصوصی)
- دسترسی نوشتن PHP به `storage/`
- HTTPS برای استفاده واقعی

Composer، MySQL، Node.js، سرویس ایمیل یا CDN لازم نیست. اگر `pdo_sqlite` در cPanel در دسترس نیست، از شرکت هاستینگ بخواهید آن را فعال کند.

## امکانات

- داشبورد مدیریتی، جست‌وجوی سراسری، گزارش‌ها، خروجی UTF-8 CSV و گزارش رویدادها
- ۲۹ ماژول آماده برای پرونده کارکنان، واحدها، حضور، مرخصی، حقوق، جذب، متقاضیان، ورود و خروج، عملکرد، اهداف، آموزش، اسناد، دارایی، هزینه، ماموریت، وظایف، اطلاعیه‌ها، مزایا، قرارداد، تغییر جبران خدمات، شیفت، کارکرد، نظرسنجی، ایمنی، انضباط، تأییدها، گواهینامه و مصاحبه خروج
- مدیریت حساب‌ها و نقش‌های مدیر، منابع انسانی، مدیر واحد و کارمند
- ثبت ورود/خروج، پیگیری مرخصی و گردش وضعیت درخواست‌ها
- بارگذاری کنترل‌شده فایل‌های سند در پوشه خصوصی
- نصب یک‌مرحله‌ای و فایل SQLite محلی
- راهنمای داخلی **درباره سامانه** با ۱۲۰ قابلیت شماره‌گذاری‌شده و راهنمای افزودن ماژول

فهرست کامل و شرح کاربرد تک‌تک ۱۲۰ قابلیت در بخش «درباره سامانه» پس از ورود ارائه شده است.

## ساختار پروژه

```text
app/
  Core/            هسته، امنیت، پایگاه داده، دسترسی و سرویس رکوردها
  Modules/         هر ماژول در پوشه مستقل و با module.php
  Views/           قالب‌های PHP رابط کاربری
assets/             CSS و JavaScript محلی
storage/            SQLite، تنظیمات نصب و بارگذاری‌های خصوصی
  uploads/          اسناد با نام تصادفی؛ دسترسی مستقیم وب مسدود است
docs/               راهنمای نصب، معماری و توسعه
install.php         راه‌انداز نصب
index.php           Front controller
```

## توسعه ماژول

برای یک فرایند متداول، پوشه‌ای در `app/Modules/<slug>/` بسازید و `module.php` را با manifest ماژول بنویسید. ماژول‌های استاندارد به‌صورت خودکار کشف می‌شوند و فهرست، جست‌وجو، فیلتر، صفحه‌بندی، فرم، اعتبارسنجی، ثبت تغییرات و خروجی CSV را از مخزن عمومی SQLite می‌گیرند؛ برای CRUD معمولی نیاز به تغییر هسته یا ساخت جدول جدید نیست.

راهنمای گام‌به‌گام و مثال کامل: [`docs/ADD_MODULE_FA.md`](docs/ADD_MODULE_FA.md)

آزمون سلامت هسته و CRUD تمام ماژول‌های استاندارد (با PHP و PDO_SQLite):

```bash
php tests/smoke.php
```

## نکات عملیاتی و امنیت

- ورودی و ذخیره تاریخ در نسخه ۱٫۰ میلادی (`YYYY-MM-DD`) است؛ رابط راست‌چین و فارسی است، اما تبدیل/نمایش تقویم جلالی در این نسخه پیاده‌سازی نشده است.
- گذرواژه‌ها با `password_hash()` ذخیره می‌شوند؛ نشست، CSRF، اعتبارسنجی سرور و محدودسازی تلاش ورود پیاده‌سازی شده‌اند.
- فایل SQLite، تنظیمات و بارگذاری‌ها زیر `storage/` قرار دارند و `.htaccess` دسترسی HTTP به آن‌ها را می‌بندد.
- پشتیبان پایگاه داده را از تنظیمات دانلود و بیرون از مسیر عمومی وب نگهداری کنید. فایل پشتیبان شامل داده‌های حساس است.
- فضای ذخیره‌سازی، سقف آپلود و محدودیت inode را با شرکت هاستینگ بررسی کنید. SQLite برای نصب تک‌سرور/ترافیک سبک تا متوسط مناسب است؛ برای چند سرور هم‌زمان یا بار نوشتن بالا، پیش از استفاده معماری پایگاه داده را بازبینی کنید.
- محاسبات حقوق و مالیات در این نسخه ابزار ثبت و محاسبه ساده خالص (پایه + مزایا − کسورات) است و جایگزین موتور قانونی حقوق و دستمزد یا مشاوره مالیاتی نیست.
- در نصب نمونه، «داده نمایشی» را فقط برای آزمایش انتخاب کنید؛ پیش از ورود داده واقعی، نصب تمیز را توصیه می‌کنیم.

## ارتقا و پشتیبان‌گیری

پیش از جایگزینی کدها از صفحه تنظیمات یک نسخه SQLite دانلود کنید. `storage/config.php` و فایل `storage/hrm.sqlite` را هنگام به‌روزرسانی کد حفظ کنید. در صورت تغییر ساختار داده، مهاجرت را نسخه‌بندی و ابتدا روی نسخه پشتیبان آزمایش کنید.
